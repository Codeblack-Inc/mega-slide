# mega-slide

발표용 슬라이드를 웹(HTML)이나 PDF로 바로 만드는 스킬. **초기 세팅 단계**로, 워크플로와 엔진은 아직 없다.

PPT(.pptx)는 만들지 않는다. 편집 가능한 PowerPoint나 보고서형 고밀도 장표가 필요하면 mega-ppt를 안내한다.

이 스킬이 호출되면 슬라이드 생성이 아직 구현되지 않았다고 사용자에게 알린다.
