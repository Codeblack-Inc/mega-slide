# 레이아웃 — Type Poster (회색 + 가는 선)

장식 없이 **글자의 크기와 굵기**(Bold 700 ↔ ExtraLight 200)로 위계를 만들고, **가는 선**으로 칸을 나눈다. 색은 mega Ink에서 한 톤 낮춘 회보라 계열뿐이고 강조색은 없다. 무대는 1920×1080(16:9). 본문형 슬라이드(`content`·`number`·`cols`·`figure`·`split`)에는 위쪽 머리글(좌: 발표 제목, 우: 직전 `section`의 제목)과 쪽 번호가 자동으로 붙는다.

## 덱 필드

| 필드 | 설명 |
|---|---|
| `title` | 발표 제목 (필수). `\n`으로 줄을 나누면 첫 줄은 Bold, 나머지 줄은 ExtraLight로 표지에 나온다 |
| `subtitle` `author` `event` | 표지·마무리에 쓰인다 (선택) |
| `slides` | 슬라이드 배열 (필수) |

## 레이아웃

| layout | 필드 | 쓰임 |
|---|---|---|
| `cover` | (덱 필드를 그대로 씀, 슬라이드에서 덮어쓸 수 있음) | 표지. 맨 위 가는 선, 화면 아래쪽에 큰 제목 |
| `section` | `title` `text`(선택) `no`(선택) | 장 구분. 오른쪽 위 작은 장 번호(자동 1, 2, …) + 아래쪽 제목. 이후 슬라이드 머리글의 섹션명이 된다 |
| `content` | `title` `body` | 큰 제목 + 아래쪽에 본문 줄(줄마다 가는 선으로 구분) |
| `statement` | `text` `note`(선택) | 한 문장을 크게. `\n`으로 줄바꿈하거나 자동으로 감는다 |
| `number` | `label` `value` `note`(선택) | 큰 숫자 하나 (`"value": "10분"`) |
| `cols` | `title` `cols`: `[{title, body}]` (2~3칸) | 칸 제목을 크게, 칸마다 위에 가는 선 |
| `figure` | `title` `image` `caption`(선택) `alt`(선택) | 그림 한 장 (mega-diagram SVG 등) |
| `split` | `title` `body` `image` `caption`(선택) | 왼쪽 글, 오른쪽 그림 |
| `closing` | `title`(기본 "감사합니다") `body`(줄 배열) | 마무리. 표지와 같은 구성 |

## 글 쓰는 법

- `body`는 줄 배열. `"- "`로 시작하면 항목(`content`·`split`에서는 줄마다 가는 선이 그어진다), 앞에 공백을 두면 바로 위 항목의 부연(`"  - "`, 작고 연하게), 그 외는 문단.
- 강조는 `**굵게**` 하나뿐이다 (색은 바뀌지 않고 한 톤 진해지며 굵어진다). `` `코드` ``도 쓸 수 있다. HTML은 이스케이프된다.
- `image`는 `deck.json` 기준 상대 경로. png·jpg·webp·gif·svg를 HTML에 내장한다. SVG는 `<img>`로 들어가므로 웹 폰트가 적용되지 않는다 — 글자는 시스템 서체로 그려진다(글자가 윤곽선인 SVG면 무관). 이 디자인에는 회색(#4A4760) 단색에 얇은 선(3px) 그림이 어울린다.

## 글자 크기는 자동

`slide.mjs`가 글자 수(한글 0.94em, 그 밖 0.6em, 공백 0.3em으로 근사)에 맞춰 제목·문장·숫자·본문의 크기를 정한다. 짧으면 최대 크기, 길면 줄어들고, 최소 크기로도 안 들어가면 빌드 때 `경고:`를 낸다.

- 표지·`statement`는 `\n`을 넣으면 그 줄들이 각각 한 줄에 들어가게, 안 넣으면 알아서 감아 쓴다.
- 본문은 줄이 많을수록(3개 이하 44px → 6개 29px) 작아진다. 잠정 기준: 본문 6줄 초과, `cols` 칸 본문 4줄 초과에 경고한다.
- 크기 전체는 `slide.mjs`의 `K`(현재 0.6) 하나로 조절한다.
- 경고는 "이 글은 이 디자인에 안 맞는다"는 뜻이다. 글을 줄이거나 장을 나눈다. 폰트를 실측한 값이 아니므로 애매하면 PNG를 직접 본다.

## 새 레이아웃 추가

`scripts/slide.mjs`의 `LAYOUTS`에 `(slide, ctx) => 안쪽 HTML` 함수를 추가하고 → `assets/slide.css`에 스타일 → 이 표에 한 줄 → `examples/sample.json`에 한 장 (테스트가 모든 레이아웃이 샘플에 쓰였는지 검사한다).
